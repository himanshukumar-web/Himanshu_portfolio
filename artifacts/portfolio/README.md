## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS v4, Lucide Icons, React Icons
- **Animations**: Framer Motion
- **Build Tool**: Vite
- **Routing**: Wouter
- **Features**: Dynamic Resume Generation (jsPDF), Email Contact Integration, Glassmorphism UI, Responsive Dark Theme

---

## 💻 Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/himanshukumar-web/Himanshu_portfolio.git
   cd Himanshu_portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the local development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
